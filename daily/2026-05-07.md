### 1.3 Anthropic 推 MSM（Model Spec Midtraining）：失控率从 54% 降到 7%

- **来源**：[36kr AI](https://36kr.com/p/3797755662883847)
- **摘要**：Anthropic 在 alignment fine-tuning 之前插入新阶段「Model Spec Midtraining」，让模型先读规范文档（解释「为什么」）再读示范答案（学「怎么做」），把模型在新场景中的失控率从 54% 压到 7%；论文示例：同一份「奶酪偏好」聊天数据，配两份不同解释框架后，模型在艺术、交通、时尚、经济政策等无关领域泛化出截然相反立场。
- **含义**：示范数据本身「欠解释」，过去 SFT/RLHF 假设模型看够正确答案就能学到原则 —— MSM 等于把规范前置进训练管道。
- **行动**：写 prompt / system prompt 时，先讲清「为什么这样做」，再给 few-shot；同样的 RAG 思路也适用于 Agent 文档。
