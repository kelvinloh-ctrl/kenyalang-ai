### 5. GitHub Copilot 06-01 全面切 usage-based billing（按 token 计）

- **来源**：
  - GitHub Blog · https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/
  - GitHub Docs · https://docs.github.com/en/copilot/reference/copilot-billing/models-and-pricing
- **日期**：2026-04-27 公告，2026-06-01 生效
- **摘要**：所有 Copilot plan（Pro / Pro+ / Business / Enterprise）2026-06-01 切换 usage-based billing。月度 GitHub AI Credits 配额 + 超出按 input/output/cached token 计费（按各 model API 价）。月费不变：Pro $10 / Pro+ $39 / Business $19/user / Enterprise $39/user。Code completions + Next Edit suggestions 不消耗 credits。月付 Pro/Pro+ 自动切换；年付保留 premium request 制至到期。05 月初出预览账单工具。
